ENCORE — START HERE

1. Install Node.js 20 or newer (https://nodejs.org) and the .NET 8 SDK
   (Mac: brew install --cask dotnet-sdk@8).
2. Copy .env.example to .env. For a quick local try, set ENCORE_LOCAL_DB=1 in .env:
   Encore then runs its own PostgreSQL inside data/postgres. Otherwise set DATABASE_URL.
3. On Mac, double-click Start_Encore.command, or in Terminal inside the folder:
     npm ci
     npm run build
     npm start
4. It opens the organizer admin:
     Organizer admin:  http://127.0.0.1:8080/admin
     Guest app:        http://127.0.0.1:8080/
5. Keep the Terminal window open while you use Encore.

Guest sign-in codes: while running on your computer without an SMS provider, messages are NOT sent.
The 6-digit code appears in the Terminal window, on a line starting with [DEV SMS - NOT DELIVERED].

Do NOT double-click admin.html or guest.html; a file preview cannot reach the server.
Table QR codes use the guest address above, which only works on this computer. Guests' phones
need a public HTTPS deployment (see README "Deploying").
Online AfroPay payments are not connected. Guests reserve and pay at the venue.
